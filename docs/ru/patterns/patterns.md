# Паттерны построения систем

## <a name="patterns-about"></a> О разделе

В разделе собраны проверенные решения, из которых складывается архитектура больших систем на Totum: как разложить данные по таблицам, как показать пользователю связанные таблицы, что считать сразу, а что — в фоне, и как держать нагрузку на сервер под контролем.

Источник примеров — **B2M**, платформа интернет-магазина на Totum PRO (товары, каталог, SKU и цены, склады, заказы, витрина). Все примеры взяты из ее работающих кодов, имена таблиц и полей — настоящие (`b2m___items`, `b2m___product_images`, …), коды местами сокращены.

Каждый паттерн описан одинаково:

+ **Задача** — какую проблему решает.

+ **Решение** — из каких таблиц, полей, настроек и кодов оно собирается.

+ **Пример из B2M** — где это сделано и как.

+ **Ловушки** — что легко сломать.

> Паттерны раздела — про устройство системы: таблицы, поля, настройки и связи между ними. Правила написания самих кодов (`~`, `selectRow` вместо нескольких `select`, `` json`…` ``, оформление `listReplace` и другие) собраны в [ARCHITECTURE.md](../../ARCHITECTURE.md) — читайте его вместе с этим разделом.

## <a name="patterns-b2m"></a> Как устроена B2M

Чтобы примеры читались в контексте, — коротко о том, как собрана система.

+ **Товары** — [таблица циклов][89] `b2m___items`: одна строка — один товар, в цикле товара — его [расчетные таблицы][1] (`b2m___item` — карточка, `b2m___additional_items`, `b2m___this_product_tabs`, `b2m___product_video_iframes`).

+ **Данные товаров** — [простые таблицы][88] с колонкой `product`: картинки `b2m___product_images`, документы `b2m___product_documents`, характеристики `b2m___product_features`, опции `b2m___product_options`, SKU и цены `b2m___sku`, размеры упаковки `b2m___shipping_dimensions`, отзывы `b2m___reviews`. Внутри цикла товара они открываются вкладками — кнопками `tab_…` таблицы `b2m___items` ([Tab в цикле][709]). Простые таблицы, а не расчетные в цикле — потому что их строки нужны всем товарам сразу: по ним ищут, фильтруют и строят каталог.

+ **Сводные данные товара** — поля строки `b2m___items` (`features_data`, `catalog_prices`, `product_images`, `reviews`, …): из таблиц данных они собираются один раз и хранятся готовыми для витрины ([Хранимые расчеты][711]). Обновляет их код действия таблиц данных — только у тех товаров, которые изменились ([Пересчет затронутых строк][712]).

+ **Каталог** `b2m___catalog` — дерево категорий. Данные фильтров категории (`filters_data`) считаются по всем товарам категории — это самый тяжелый расчет системы, его делает демон ([Тяжелые расчеты в фоне][714]).

+ **Дерево навигации** — пользователь видит ярлыки, сами таблицы лежат в технической папке «Перемещенные таблицы» ([Таблица с подтаблицами в дереве][710]).

+ **Временные таблицы** — окна редактирования списков (уровни цен, приоритет складов, …), которые открываются из ячеек с параметрами и строятся автозаполнением ([Автозаполнение через h_insert][715]).
