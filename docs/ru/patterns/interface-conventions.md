# Оформление интерфейса

Соглашения, по которым пользователь с первого взгляда понимает состояние таблицы: что заполнено, что выключено, где есть дополнительная информация, почему нельзя добавить строку. Цвета записаны [пользовательскими цветами][654] `##name` — они переключаются вместе с темой оформления.

## <a name="pt-ui-panel"></a> Контекстная панель

+ **Тексты — в широкой панели.** У полей [Текст][130], [Данные][38] и у полей, в панели которых выводятся тексты или HTML, ставьте [Ширину контекстной панели][572] `Широкая` (длинные тексты — `Очень широкая`): в узкой панели текст читать неудобно.

+ **Есть информация в панели — покажите иконку.** Если у ячейки есть панель с текстом или кнопками ([panelButton][565], `p`-секции форматирования), пользователь об этом не знает, пока не кликнет правой кнопкой. Сообщайте об этом иконкой — хорошо подходит `angle-down`:

	```totum
	f2=: setFormat(condition: $#nfv != $#lc; icon: "angle-down")

	p1=: panelButton(condition: $#nfv != $#lc; code: $clear; text: "Очистить"; icon: "trash"; refresh: true)
	```

	В B2M так оформлены `redirect_list` (редиректы с кнопкой «Очистить»), `sku` в `b2m___product_images`, флаг `update_filters_data` с кнопкой «Обновить фильтры».

+ **Кнопки панели — вне ролей редактирования.** На кнопки контекстной панели не действуют «только для чтения» и роли редактирования поля: их видит и может нажать любой, кому видно поле. Если кнопка должна быть доступна только части ролей — пропишите это явно условием по [$#nr][725]:

	```totum
	p1=: panelButton(condition: $#nr = json`[1, 4]`; condition: $#nfv != $#lc; code: $clear; text: "Очистить"; refresh: true)
	```

	Для опасных действий продублируйте проверку роли в самом коде кнопки — условие скрывает кнопку, а проверка в коде защищает действие.

## <a name="pt-ui-colors"></a> Цвета состояний

| Состояние | Формат | Пример из B2M |
|---|---|---|
| Значение выбрано, но по другим условиям не действует | `color: ##lightgray` | `b2m___sku`: «Отрицательный лимит» серый, если тип учета не «any»; «Установить при нулевом остатке» — если тип учета не «only_from_stock»; остатки — если учет не ведется |
| Важное не заполнено или требует действия | `background: ##tomato; color: "white"` | `b2m___shipping_method`: пустой ключ метода — `text: "Укажите ключ"`; кнопки генерации HTML в `b2m___catalog`, когда HTML устарел |
| Переключатель включен — и это должно быть видно | `background: ##yellowgreen` | `b2m___shipping_method`: активный метод доставки (выключенный — `##tomato` и белый текст) |

```totum
f1=: setFormat(condition: $#nfv = ""; background: ##tomato; color: "white"; text: "Укажите ключ")
```

```totum
f1=: setFormat(condition: $#nfv = true; background: ##yellowgreen)

f2=: setFormat(condition: $#nfv = false; background: ##tomato; color: "white")
```

```totum
f3=: setFormat(condition: $#nfv != ""; condition: #tracking_type != "any"; bold: false; color: ##lightgray)
```

## <a name="pt-ui-buttons"></a> Кнопки

+ **Надписи кнопок — КАПСОМ**: `ОТКРЫТЬ`, `ОБНОВИТЬ УРОВНИ`, `СОХРАНИТЬ ЦЕНЫ`. Исключение — кнопки в специальных плейсментах (панель кнопок над таблицей `buttons`, меню `dotbuttons` [setTableFormat][317], кнопки панели): там надписи обычные — «Загрузить картинки», «Пересчитать товары».

+ **Короткие кнопки — с пустой надписью и иконкой.** Для частых действий в строке оставьте [текст кнопки][137] пустым и задайте иконку форматированием — колонка получается узкой, а действие узнаваемым:

	```totum
	f1=: setFormat(icon: "map-signs")
	```

	В B2M так в `b2m___sku` сделаны «Движение по складу» (`map-signs`) и «Добавить на склад» (`plus-square`).

## <a name="pt-ui-tables"></a> Таблицы

+ **Пользовательским таблицам — [иконки][533].** По иконке таблицу находят в дереве быстрее, чем по названию. В B2M иконки есть у всех рабочих таблиц: товары — `cubes`, SKU — `barcode`, картинки — `file-image-o`, документы — `file-pdf-o`.

+ **Заблокировали добавление по условию — объясните почему.** Вместе с `blockadd` выведите `tablecomment` с причиной; комментарии таблицы принято начинать с `@`:

	```totum
	f3=: setTableFormat(condition: $exist_null != ""; blockadd: true; tablecomment: str`"@ нельзя добавить новый товар, так как в базе <a href='" + $get_url + "'>есть товар</a> у которого не указан url"`)

		~exist_null: select(table: $#ntn; field: 'id'; where: 'url' = "")
		get_url: tableUrl(table: 'b2m___item'; cycle: $exist_null)
	```

	Это `b2m___items`: комментарий сразу ведет к товару, из-за которого добавление закрыто.

+ **Большие таблицы — сразу с [разбивкой на страницы][469] и верхними границами через `**`.** Таблица, в которой будут тысячи строк, без пагинации однажды откроется у пользователя на десятках тысяч строк. Ставьте разбивку при создании таблицы и ограничивайте, сколько строк пользователь может попросить:

	| Таблица B2M | `pagination` |
	|---|---|
	| `b2m___items` | `100/50**1000/100` |
	| `b2m___sku` | `100/50**5000/500` |
	| `b2m___stock` (новые сверху) | `200/50/desc**2000/200/desc` |
	| `b2m___cities` | `2000/200**6000/600` |

## <a name="pt-ui-sanitize"></a> Данные в HTML — только экранированные

`tablehtml`, `tablecomment`, HTML-поля, тексты окон выводятся как HTML. Если в них попадают данные, которые вводили пользователи или внешние системы (названия, комментарии, ответы API), экранируйте их — иначе одна строка с `<script>` или незакрытым тегом сломает страницу или выполнит чужой код:

```totum
=: setTableFormat(tablehtml: str`"<b>Клиент:</b>" ++ $safe_name`)

safe_name: strReplace(str: #h_client_name; from: $from; to: json`["&amp;", "&lt;", "&gt;", "&quot;", "&#39;"]`)
	~from: listCreate(item: "&"; item: "<"; item: ">"; item: '"'; item: "'")
```

`&` заменяется первым — иначе он испортит уже вставленные `&lt;`. Экранирование, которое нужно во многих местах, оформляют [пользовательской функцией][657] или [ext-функцией][505] — в B2M для этого есть `extSanitize` ([Расширение системы][736]).
