# Tab в цикле со скрытыми префильтрами

## <a name="pt-tabs-task"></a> Задача

У строки [таблицы циклов][89] есть связанные данные, которые удобно править прямо внутри цикла, но которые не могут быть [расчетной таблицей цикла][1]: их много (десятки тысяч строк), их строки нужны другим таблицам системы (поиск, каталог, отчеты по всем циклам) или к ним нужен доступ и вне цикла.

Такие данные хранятся в [простой таблице][88] с колонкой-ссылкой на цикл, а в цикл выводятся вкладкой — механизмом [Tab для циклов][705]. Чтобы вкладка выглядела как часть цикла, в ней прячут префильтр привязки, саму колонку привязки и другие служебные поля, а добавлять строки разрешают только из вкладки.

## <a name="pt-tabs-solution"></a> Решение

1. В целевой простой таблице:

	+ Колонка привязки к циклу — например `product`, [селект][23] на таблицу циклов.

	+ Префильтр `fl_product`, привязанный к этой колонке ([Name поля в строчной части][18] = `product`) с [Все][206] (`*ALL*`) по умолчанию: при обычном открытии таблицы из дерева можно смотреть строки всех циклов или выбрать один.

	+ Префильтр-признак `fl_tab` — [чекбокс][126] **без привязки** к колонке, [видно ролям][178] — только Создатель. Не привязанный префильтр ничего не фильтрует и работает как переменная ([задачи префильтра][706]): по нему таблица узнает, что открыта как вкладка.

2. В таблице циклов — кнопка с `name` с префиксом `tab_`, ее код действия открывает целевую таблицу в том же окне и передает оба префильтра:

	```totum
	=: linkToTable(table: 'b2m___product_images'; filter: 'fl_product' = #id; filter: 'fl_tab' = true; target: "self")
	```

3. В [форматировании таблицы][41] целевой таблицы — по `fl_tab` спрятать служебные поля, вывести заголовок по циклу и закрыть добавление вне вкладки:

	```totum
	f1=: setTableFormat(condition: #fl_tab = false; blockadd: true)

	f2=: setTableFormat(condition: #fl_tab = true; fieldshide: json`["fl_tab","fl_product","product"]`; tabletitle: str`"Характеристики товара:" ++ #s.fl_product`; browsertitle: true)
	```

	+ `fieldshide` прячет префильтры и колонку привязки: во вкладке они не нужны, цикл и так понятен.

	+ `#s.fl_product` — [отображаемое значение][719] селекта (название товара), а не его id.

	+ `blockadd` при `fl_tab = false`: из дерева, где префильтр может стоять на `*ALL*`, строку не добавить — колонка привязки осталась бы пустой.

4. Колонка привязки при добавлении получает значение префильтра автоматически — [автоподстановка][706] привязанного префильтра в [строку добавления][63]. Автоподстановка работает для колонки без [кода][27], видимой в web; вводиться при добавлении ей не обязательно. Саму колонку делают нередактируемой: строка не должна «переехать» в другой цикл.

## <a name="pt-tabs-b2m"></a> Пример из B2M

В `b2m___items` (товары) — восемь вкладок: `tab_images`, `tab_documents`, `tab_features`, `tab_shipping_dimensions`, `tab_options`, `tab_sku`, `tab_reviews`, `tab_elements`. Каждая открывает свою простую таблицу данных товара:

```totum
=: linkToTable(table: 'b2m___product_features'; filter: 'fl_product' = #id; filter: 'fl_tab' = true; target: "self")
```

Форматирование таблицы `b2m___product_features`:

```totum
f0=: setTableFormat(buttons: json`["h_features_list"]`; topbuttons: false)

f1=: setTableFormat(condition: #fl_tab = false; blockadd: true)

f2=: setTableFormat(condition: #fl_tab = true; fieldshide: json`["fl_tab","fl_product","product"]`; tabletitle: str`"Характеристики товара:" ++ #s.fl_product`; browsertitle: true)
```

Те же таблицы есть в дереве (раздел «Данные товаров») — там они открываются без `fl_tab`, с префильтром товара и колонкой `product`.

В `b2m___product_images` строки добавляются не строкой добавления, а кнопкой загрузки файлов. Кнопка проверяет, что товар выбран, и передает его в код вставки переменной:

~~~totum
a1=: if(condition: #fl_product = "*ALL*"; then: $err)

	err: errorException(text: "Для добавления картинок выберите Товар")

a2=: linkToFileUpload(title: "Загрузить картинки (не более 5 шт за один раз)"; code: $insert; limit: 5; type: "image/png,image/jpeg,image/jpg,image/webp"; var: "product" = #fl_product; refresh: true)

```insert:totum
=: listReplace(list: $#input; action: $insert; value: "value")

insert: insert(table: $#ntn; field: 'product' = $#product; field: 'image_raw' = json`[$#value]`; after: $sel_last_id; log: true)
	sel_last_id: select(table: $#ntn; field: 'id'; order: 'n' desc)
```
~~~

Вкладка может получать и дополнительные параметры. `tab_sku` берет цель окна и данные поиска из переменных с значениями по умолчанию — поэтому ее можно и нажать как вкладку, и вызвать из другого кода через [execButton][444] с другими значениями:

```totum
=: linkToTable(table: 'b2m___sku'; filter: 'fl_product' = #id; filter: 'fl_tab' = true; filter: 'fl_search_field' = $data; target: $target)

target: var(name: "target"; default: "self")

data: var(name: "filter_data"; default: $#lc)
```

## <a name="pt-tabs-traps"></a> Ловушки

+ Префильтр-признак (`fl_tab`) **не привязывайте** к колонке: привязанный префильтр фильтрует строки, а признаку нужно только сообщить, откуда открыта таблица.

+ `fieldshide` прячет поля от показа, но не меняет права. Если пользователь не должен переключать цикл внутри вкладки, префильтр привязки должен быть недоступен ему для редактирования (тогда он еще и ограничивает доступ к строкам, см. [задачи префильтра][706]) — или скрыт по ролям, как советует [Tab для циклов][705].

+ Без `blockadd` вне вкладки строку можно добавить с пустой колонкой привязки — такая строка не попадет ни в один цикл.

+ Открытая вкладкой таблица — обычная простая таблица, а не таблица цикла: цикл в ее кодах берите из префильтра (`#fl_product`) или из колонки привязки строки, а не из `$#nci`.

+ Порядок вкладок и их видимость для ролей задаются настройками самих кнопок `tab_…` в таблице циклов (сортировка, видимость ролям).
