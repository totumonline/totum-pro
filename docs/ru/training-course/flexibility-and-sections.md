# Адаптивность и секции

## <a name="sections"></a> Секции

видео: [YouTube](https://www.youtube.com/watch?v=Ux5nUgAguvU)

### <a name="sections-qa"></a> Вопросы и ответы

#### <a name="sections-q1"></a> Для чего нужны секции?

Для лучшего визуального отображения и группировки большого количества полей в `хедере` и `футере`.

Очень подробно [про секции в документации][456].

#### <a name="sections-q2"></a> Какие плейсменты можно делить на секции?

`Хедер` и `Футер`.

#### <a name="sections-q3"></a> С какого места начинается следующая секция?

С места в котором указаны параметры следующей секции:

+ Активен перенос строки параметром [c новой строки][175].

+ Заполнены параметры секции. если параметры секции не заполнены, то поле с переносом и последующие поля будут относится к предыдущей секции.

#### <a name="sections-q4"></a> Как объединить поля в блоки?

Это можно сделать двумя путями — через форматирование поля функцией [setFloatFormat][447] или через параметр секции:

+ [setFloatFormat][447] — надо задать параметр `blocknum` указав номер блока. Поля с одинаковми номерами и стоящие рядом — попадут в одну группу.

+ Через настройки секции указав:

		blocknum: name_field_1, name_field_2 : 1

Первая строка в настройках секции всегда зарезирвирована под название секции. Если вы хотите, что бы название было пустым — оставьте первую строку пустой.

Можно заполнить название секции в первой строке и указать `label: false` — тогда заголовок секции будет видеть только `Создатель`.

#### <a name="sections-q5"></a> Как скрыть заголовки у полей?

Через параметры секции параметром `title`.

Если указать:

	title: false

То все заголовки полей в секции будут скрыты.

Если указать:

	title: field_name_1, field_name_2 : false

Заголовок будет скрыт только у полей `field_name_1` и `field_name_2`.

#### <a name="sections-q6"></a> Как скрыть стандартную обводку полей и сделать вид кнопок крупнее?

Это делается через параметр секции `plate`.

#### <a name="sections-q7"></a> Как перенести на следующую строку поле внутри блока?

Это можно сделать двумя путями — через форматирование поля функцией [setFloatFormat][447] или через параметр секции:

+ [setFloatFormat][447] — надо задать параметр `nextline` указав `true`.

+ Через настройки секции указав:

		nextline: name_field_1, name_field_2 : true

В этом случае поля будут перенесены внутри блока. В отличие от параметра поля [c новой строки][175], которй создает новый блок — поле остается в том же блоке.

#### <a name="sections-q8"></a> Как перенести поле на следующую строку вне блока?

Использовать параметр поля [c новой строки][175].

#### <a name="sections-q9"></a> Как настроить высоту поля?

Параметры `height` и `maxheight`.

+ `height` — жестко задает высоту.

+ `maxheight` — высота будет увеличиваться в зависимости от содержания поля.

#### <a name="sections-q10"></a> Как заменить плашку у группы на обводку?

Параметр `plate: false` + `border: true` — в таком варианте настройки будут применены ко всем группам.

Если указать `plate: 1,2 : false` — настройка будет применена только к группам `1` и `2`.

#### <a name="sections-q11"></a> Как добавить отступы между полями?

Параметр `gap` — указыватеся в пикселях.

#### <a name="sections-q12"></a> Как поместить заголовки слева от полей?

Параметр `titleleft`. Указывается в пикселях или в `%` от ширины поля.

Общая ширина поля остается неизменной — заголовок занимает часть общей ширины слева или справа если используется `titleright`.

### <a name="adaptability-qa"></a> Вопросы и ответы

#### <a name="adaptability-q1"></a> Когда поле переносится на следующую строку и как этим управлять?

На следующую строку переносится правое поле в блоке если поля в линию перестали помещатся по ширине окна при их базовых ширинах.

#### <a name="adaptability-q2"></a> Как переносить поля на следующую строку только вместе?

Для этого используется параметр `glue` – они приклеивает поле к полю находящемуся левее и они будут переносится на следующую строку только вместе.

#### <a name="adaptability-q3"></a> Как автоматически расширять поле если для этого есть место?

Параметром `maxwidth` — задается в пикселях. Если нескольким полям в блоке заданы `maxwidth`, то они расширяются пропорционально соотношению их базовых ширин.

#### <a name="adaptability-q4"></a> Как автоматически расширять поле при его переносе на следующую строку?

Для этогоиспользуется параметр `fill: true`.

#### <a name="adaptability-q5"></a> Как задать ширину с которой поле будет переносится на следующую строку?

Если вы хотите, что бы поле перенеслось на следующую строку до того как достигнет своей минимальной ширины — задайте `breakwidth`.

#### <a name="adaptability-q6"></a> Как задать разный вид параметров для состояния до переноса и после?

Многие параметры имеют две настройки — до переноса элемента или после.

Указываются через `/`:

	outline: 1 : true/false

Означает, что до переноса группа `1` будет иметь обводку — после переноса обводка будет выключена.
