# Учебный курс

## <a name="training-course-1"></a> Документация

[**Документация**](/) — это `алфавитный справочник`, если вы только начинаете осваивать Totum, то в нем может быть сложно сориентироваться.

## <a name="training-course-2"></a> Учебный курс

**Учебный курс** — это последовательные ~180 заданий по 5 минут от простого к сложному в формате `how-to`, которые позволят вам максимально быстро приступить к разработке своего проекта!

## <a name="training-course-3"></a> Мастерклассы

Также вы можете начать с [Мастеркласса][659] на котором мы делаем небольшой законченный проект — это позволит вам сориентироваться как комплексно собирать проекты на Totum.

## <a name="training-course-4"></a> Как развернуть сервер

Рекомендуем всем использовать [автоустановку на ubuntu][497].

## <a name="training-course-5"></a> Где найти примеры из учебного курса

В репозитории [https://github.com/totumonline/ttm-samples](https://github.com/totumonline/ttm-samples) можно найти файл для установки `samples/course_sample_only_for_clean_systems.json.gz.ttm` и видео по установке.
