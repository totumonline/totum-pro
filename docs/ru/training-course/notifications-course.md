# Нотификации

## <a name="general"></a> Общее

### <a name="general-qa"></a> Вопросы и ответы

#### <a name="general-q1"></a> Запись в какой таблице создает нотификацию?

`Системные таблицы` —> `Основные` —> `Нотификации` —> `Нотификации`

Одна строка — одна нотификация!

[Про нотификации в документации][431]

#### <a name="general-q2"></a> Если нужно создать одну и ту же нотификацию для трех пользователей, то сколько строк надо добавить в таблицу нотификаций?

Для каждого пользователя нужно добавить по строке.

#### <a name="general-q3"></a> Зачем нужны коды нотификаций?

Коды нотификаций — это шаблоны нотификаций.

`Системные таблицы` —> `Основные` —> `Нотификации` —> `Коды нотификаций`

У них есть `name` и `code`. Когда нотификация формируется для пользователя — она использует `code` из `Коды нотификаций`.

#### <a name="general-q4"></a> Как создать нотификацию вручную?

`Системные таблицы` —> `Основные` —> `Нотификации` —> `Добавление нотификации`

#### <a name="general-q5"></a> Какая функция создает нотификацию кодом?

Надо добавить строку в таблицу `notifications`, те:

```totum

=: insert(table: 'notifications'; field: 'code' = "admin_text"; field: 'active_dt_from' = $#ndt; field: 'title' = "Заголовок нотификации, который будет показан в таблице последних нотификаций"; field: 'user_id' = 1; field: 'vars' = $vars; field: 'active' = true)

	vars: rowCreate(field: "text" = "Текст нотификации")

```

В Кодах нотификаций:

```totum

=: linkToDataHtml(title: 'Важное сообщение'; html: $#text)

```

#### <a name="general-q6"></a> По каким условиям можно создать нотификацию?

По любым — если в таблице нотификаций создана строка.

#### <a name="general-q7"></a> Какой параметр обязательно нужно передать в таблицу нотификаций, что бы она показалась у пользователя?

Все параметры таблицы `notifications` должны быть заполнены.

Особенно внимательно относитесь к `active` - его часто забывают передать как `true`.

## <a name="additionally"></a> Дополнительно

### <a name="additionally-qa"></a> Вопросы и ответы

#### <a name="additionally-q1"></a> Можно ли передать нотификацию с активацией в будущем времени?

Да, в этом случае явно передайте в `insert` значение для `active_dt_from`.

#### <a name="additionally-q2"></a> Как посмотреть последние нотификации?

Кнопка `колокольчик` рядом с ником сверху справа у окна Totum.

#### <a name="additionally-q3"></a> Можно ли использовать html в нотификации?

Да, нотификации поддерживают `html` если в коде нотификации вы вызываете именно [linkToDataHtml][309].

Если вы используете [linkToDataText][307] — то нет.

#### <a name="additionally-q4"></a> Можно ли сделать ссылку на таблицу внутри цикла, чтобы пользователь сразу смог перейти в заказ, например?

Да. Сконструируйте ее через `str`. В нотификацию этот путь надо передать как ссылку `html`:

```totum

=: linkToDataHTML(title: $#title; html: $replace)

	url: str`"https://" + $#nh + "/TREE_NUMBER/CYCLE_TABLE_ID/" + $#cycle_id + "/TABLE_ID"`

replace: textByTemplate(text: $html; data: json`["url":$url]`)

```html:html
<div>
...
...
{url}
...
</div>

```
```

#### <a name="additionally-q5"></a> С каким интервалом проверяется наличие нотификаций?

Зависит от настройки в `Системные таблицы` —> `Основные` —> `Настройки и крон` —> `Настройки` —> `periodicity`.

#### <a name="additionally-q6"></a> Как кодом отключить ненужную нотификацию у пользователя?

Нужно либо удалить строку с нотификацией из `notification` или, если вы хотите, чтобы она осталась в списке нотификаций — поставить `active` в `false`.

## <a name="notification-in-the-form-of-a-time-table"></a> Нотификация в виде временной таблицы

### <a name="notification-in-the-form-of-a-time-table-qa"></a> Вопросы и ответы

#### <a name="notification-in-the-form-of-a-time-table-q1"></a> Пример: пример как создать нотификацию в виде временной таблицы

Нотификацию можно открыть не только как `text` или `html`, но и как временную таблицу, передав в нее параметры.

Например таким образом можно показать информацию с карточки клиента с действиями, которые можно будте выполнить прямо из окошка нотификации.

Пример из документации:

```totum
=: linkToDataTable(table: 'tmp_table'; title: "Заголовок нотификации"; height: 400; params: $row; data: $data)

row: rowCreate(field: "h_test" = $#val)

data: rowListCreate(field: "goods" = "LIST_GOODS"; field: 'count' = "LIST_COUNT")

```
