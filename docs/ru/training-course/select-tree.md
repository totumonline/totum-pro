# Селект-дерево

## <a name="select-tree-field-type"></a> Тип поля Селект-дерево

### <a name="select-tree-field-type-qa"></a> Вопросы и ответы

#### <a name="select-tree-field-type-q1"></a> Значение, которое хранит Селект-дерево, отличается от Селекта?

Нет. Это Селект, который отображается во всплывающем окне и имеет древовидную структуру.

#### <a name="select-tree-field-type-q2"></a> Какой дополнительный параметр нужно указать, что бы работало Селект-дерево?

Дерево строится функцией [selectRowListForTree][228].

Ключевым дополнительным параметром является `name`-параметр `parent` — в нем должно быть указано `name` поля, в котором хранится какая строка является родительской.

Также если вам нужно, что бы дерево начиналось не от корня, а от каких-то конкретных значений надо задать `roots`.

#### <a name="select-tree-field-type-q3"></a> Что значит Дерево строится по одной таблице?

Это значит, что значения папок и значения внутри папок лежат в одной таблице.

Должно быть включено [Дерево строится по одной таблице][198].

#### <a name="select-tree-field-type-q4"></a> В этом случае можно ли выбирать в качестве значения папки? Можно ли отключить?

В этом случае папки можно выбирать в качестве значений.

Но это можно отключить сняв активность с параметра [папки можно выбирать][199].

#### <a name="select-tree-field-type-q5"></a> Что значит создать Селект-дерево по другой таблице?

это означает, что у нас структура папок лежит в отдельной таблице от значений.

Те у нас два дерева вложенных друг в друга. Папки являются вложенным деревом.

#### <a name="select-tree-field-type-q6"></a> Можно ли в этом случае выбирать папки в качестве значения? Почему?

В этом случае папки нельзя выбирать, тк их значения хранятся в отдельной таблице.

## <a name="treeview-based-on-select-tree"></a> Tree-вью на основе селект-дерева

видео: [YouTube](https://www.youtube.com/watch?v=TBHHT-AZHvs)

### <a name="treeview-based-on-select-tree-qa"></a> Вопросы и ответы

#### <a name="treeview-based-on-select-tree-q1"></a> Пример: пример как оформить таблицу в виде дерева

Tree-вью является одной из самых сложных тем в `totum`. Поэтому изучаем в два этапа.

**Первый** — это `папки и значения в одной таблице`. Для того, что бы оформить таблицу как дерево нам нужно:

1. Создать поле в строчной части типа Строка для названия папки/элемента.

2. Создать поле тип Дерево с `name` — `tree`.

3. Заполнить код-селекта:

	```totum

	=: selectRowListForTree(table: $#ntn; field: 'nazvanie'; parent: $#nf; order: 'nazvanie' asc)

	```
4. Убедиться, что включены параметры [дерево строится по одной таблице][198] и [папки можно выбирать][199].

На этом месте можно сохранить и посмотреть, что происходит. При добавлении мы заполняем название и в поле `tree` можем выбрать родителя для строки.

Добавьте так несколько строк. Если `tree` остается пустым — то это означает, что эта строка будет на верхнем уровне.

5. Дальше идем в настройки `tree` и включаем параметр [тип таблицы-дерева][529] в значении `по этой таблице`. А также ставим [Загрузить все][531] и [Открыть все][530].

6. Теперь нам нужно оформить форматирование поля `tree`. Скопируйте туда такой код и поставьте ширину полю `200`:

	```totum
	// Убираем пути и делаем заливку
	f1=: setFormat(text: " "; background: "whitesmoke"; editbutton: true)

	// Отключаем разворачивание пустым папкам и заменяем им иконку
	f2=: setFormat(condition: #id != $sel; icon: "folder-o";  expand: false)
		sel: selectList(table: $#ntn; field: 'tree')

	// Убираем поле tree из панели
	f3=: setFormat(hide: "extpanel" = true)

	```

#### <a name="treeview-based-on-select-tree-q2"></a> Какой name должно иметь поле, чтобы появилась возможность включить tree-вью?

`tree`

#### <a name="treeview-based-on-select-tree-q3"></a> Какой параметр должен быть включен у поля tree, чтобы сработало отображение tree-вью?

[Тип таблицы-дерева][529].

#### <a name="treeview-based-on-select-tree-q4"></a> Что значит «По текущей таблице»?

Это значит, что структура дерева и конечные значения находятся в одной таблице.

#### <a name="treeview-based-on-select-tree-q5"></a> Можно ли настроить отображение поля tree?

Да, через код форматирования. Используйте референс приведенный выше как образец.

#### <a name="treeview-based-on-select-tree-q6"></a> Что значит по «Другой таблице»?

Это значит, что дерево у нас хранится в одной таблице, а его значения в другой.

#### <a name="treeview-based-on-select-tree-q7"></a> Пример: пример формирования дерева «по другой таблице»

Для примера мы используем первую таблицу как источник дерева и создадим еще одну со значениями.

1. Создаем еще одну таблицу.

2. Создаем пару полей в строчной части в которых будут значения.

3. Создаем поле с `name` = `tree` с типом `Селект-дерево`. В коде селекта пишем:

	```totum
	=: selectRowListForTree(table: 'table_tree_1'; field: 'title'; parent: 'tree'; order: 'title' asc)

	```

	Включаем настройки [дерево строится по одной таблице][198] и [папки можно выбирать][199] тк дерево в таблице `table_tree_1` строится по ОДНОЙ! таблице.

4. Теперь можем добавить несколько строк со значениями выбирая в каких папках они будут расположены. ничего сложного.

5. Включаем параметр [тип таблицы-дерева][529] в значении `по другой таблице` тк дерево из `table_tree_1` находится в другой таблице. А также ставим [Загрузить все][531] и [Открыть все][530].

6. Сразу добавим форматирование поля `tree` и поставим ему ширину `80`:

	```totum

	f1=: setFormat(editbutton: true; text: " "; background: "whitesmoke")

	```
7. Сделаем автоматический отступ для значений в первом поле слева со значениями:

	```totum

	f1=: setFormat(tab: $count)

	count:  #l.tree * 22

	```

#### <a name="treeview-based-on-select-tree-q8"></a> Как у варианта «По другой таблице» показать не все дерево, а только его часть?

Если мы хотим показать не все дерево, а только его часть, то в код `tree` надо передать `list` из `roots`.

Это основания (по умолчанию `id`) тех родительских элементов, которые должны быть на верхнем уровне.

#### <a name="treeview-based-on-select-tree-q9"></a> Как сделать так, что бы в варианте «По другой таблице» у папок тоже были строки со значениями?

Для этого добавляется еще одно поле с `name` = `tree_category `.

В поле кодом или вручную должно быть выбрано значение соответсвующее `id` или `bfield` папки, которой соответсвует строка.

Обратите внимание, что в поле tree указана родительская категория, поэтому значение в `tree` и `tree_category` отличаются на один уровень.

Для корректной работы поле `tree_category` должно быть видимым пользователю. Может быть [скрытым по умолчанию][168].
