# Настройки полей и таблиц продвинутый уровень

## <a name="obligatory-and-regexpv"></a> Обязательное и regexp

### <a name="obligatory-and-regexpv-qa"></a> Вопросы и ответы

#### <a name="obligatory-and-regexpv-q1"></a> Как сделать поле обязательным для заполнения при добавлении строки и изменении?

Нужно включить параметр поля [Обязательное][157].

Когда он включен — Totum отслеживает, чт бы поле не содержало пустоту `""` или пустой список `$#lc`.

#### <a name="obligatory-and-regexpv-q2"></a> Какое значение не пропускает Обязательное?

+ `""` — пустота.

+ `$#lc` — пустой список.

#### <a name="obligatory-and-regexpv-q3"></a> Если поля уже добавлены в простую таблицу с пустыми значениями, то можем ли мы назначить полю Обязательное?

Да, можем. Но строки содержащие пустое значение в обязательном поле можно будет пересчитать только назначив значение в это поле.

#### <a name="obligatory-and-regexpv-q4"></a> В какой момент возникнет ошибка если поле останется пустым?

При любом изменении затрагивающем пересчет единицы пересчета в которую попадает пустое обязательное.

#### <a name="obligatory-and-regexpv-q5"></a> Если то же самое в расчетной и временной таблице?

В этом случае вся таблица встанет с ошибкой.

#### <a name="obligatory-and-regexpv-q6"></a> Если ошибка возникнет в расчетной в цикле, то будет ли пересчитан цикл?

Нет, не будет.

#### <a name="obligatory-and-regexpv-q7"></a> Как настроить простые ограничения для вводимых в поле данных?

Можно ограничить ввод значений при помощи [формата валидизации ввода (regexp)][151].

Например:

+ `^\d+$` — только положительные целые числа включая 0.

+ `^[1-9]\d*$` — только положительные целые числа исключая 0.

+ `^(.+@.+\..+|.{0})$` — проверка формата email.

#### <a name="obligatory-and-regexpv-q8"></a> Для чего нужны настройки предупреждений при изменении в поле?

Дополнительная защита от случайного изменения.

На самом деле люди научаются нажимать `OK` в таких окошках автоматически, поэтому если вы хотите посильнее обратить на это внимание, то вынесите ввод значения в `linkToInput`:

```totum
= : linkToInput(title: "Контроль изменения"; html: "Предупреждение здесь!"; code: "=: set(table: $#ntn; field: 'h_input_s_pinkodom' = $#input)"; refresh: true; button: "Подтвердить")

```

Для этого у поля отключается редактирование и ставится триггер по клику.

И предупреждение добавляйте в параметр `html`.

## <a name="optimize-list-processing-and-notloaded-for-the-data-field"></a> Оптимизация обработки списков и notloaded для поля данные?

### <a name="optimize-list-processing-and-notloaded-for-the-data-field-qa"></a> Вопросы и ответы

#### <a name="optimize-list-processing-and-notloaded-for-the-data-field-q1"></a> Зачем нужно максимальное количество выводимых элементов для списков?

[Максимальное количество выводимых элементов][166] — для ускорения их загрузки.

#### <a name="optimize-list-processing-and-notloaded-for-the-data-field-q2"></a> Зачем нужен notloaded для поля типа Данные?

Иногда в Данные хранятся большие `json` и это может вызывать зависание загрузки таблиц в момент, когда они загружают несколько сотен или тысяч таких строк.

[notloaded][534] сообщает базе данных, что ей в принципе не нужно читать содержимое этих полей при загрузке таблицы, что кардинально ускоряет загрузку.

#### <a name="optimize-list-processing-and-notloaded-for-the-data-field-q3"></a> Какое значение будет получать код форматирования при активном notloaded?

Если установлено, то в таблицу при загрузке передается значение `**NOTLOADED**`.

## <a name="group-change-when-selecting-in-one-or-more-columns"></a> Групповое изменение при выделении в одной или нескольких колонках

### <a name="group-change-when-selecting-in-one-or-more-columns-qa"></a> Вопросы и ответы

#### <a name="group-change-when-selecting-in-one-or-more-columns-q1"></a> Какой параметр должен быть активен, чтобы поля изменялись по вертикали?

[Групповое изменение][163]

#### <a name="group-change-when-selecting-in-one-or-more-columns-q2"></a> Как используя групповое изменение копировать значение в другие поля?

Выделить несколько полей, потом открыть на редактирование поле, в котором расположено нужное нам значение и нажать «применить ко всем».

#### <a name="group-change-when-selecting-in-one-or-more-columns-q3"></a> Какой параметр должен быть активен, чтобы поля изменялись при выделении по горизонтали?

[При выделенных других колонках][164]

#### <a name="group-change-when-selecting-in-one-or-more-columns-q4"></a> Он должен быть включен у всех выделенных колонок?

Да, он должен быть включен во всех выделенных колонках. Если хотя бы в одной из колонок он выключен, то кнопка сохранения для группы будет отсутствовать.

## <a name="logging-and-access-to-logs"></a> Логирование и доступ к логам

### <a name="logging-and-access-to-logs-qa"></a> Вопросы и ответы

#### <a name="logging-and-access-to-logs-q1"></a> Если параметр логгирование отключен, то будут ли записываться изменения?

Нет

#### <a name="logging-and-access-to-logs-q2"></a> Какие параметры записываются в лог?

`id` пользователя, время совершения действия, тип (добавление/изменение), значение введенное в поле, значение после изменения.

Для Селектов в «значение после изменения» записывается `отображение`.

#### <a name="logging-and-access-to-logs-q3"></a> Если изменение происходит в поле Селект или Селект дерево, то какое значение будет записано в поле Введено?

Значение, оно же `основание`.

#### <a name="logging-and-access-to-logs-q4"></a> Если изменение происходит в поле Селект или Селект дерево, то какое значение будет записано в поле значение после изменения?

Отображение.

#### <a name="logging-and-access-to-logs-q5"></a> Будет ли оно изменено при изменении таблицы источника селекта?

Нет

#### <a name="logging-and-access-to-logs-q6"></a> Записываются ли логи временных таблиц?

Нет, даже если в полях стоят галочки [c логированием][185].

#### <a name="logging-and-access-to-logs-q7"></a> Записывают ли логи изменение значений вычисленных кодом?

Нет

#### <a name="logging-and-access-to-logs-q8"></a> Что должно быть включено, что бы в лог записалось значение установленное Кодом действия?

Для этого в функции действия записвающей в поле должен быть указан параметр `log:true`.

В этом случае в типе действия  в логах будет указано — `Скрипт`.

#### <a name="logging-and-access-to-logs-q9"></a> Можно ли вместо Скрипт передать описание?

Также в `log` можно передать текст, тогда он будет записан вместо `Скрипт` —  `log: "Оплата картой"`

#### <a name="logging-and-access-to-logs-q10"></a> На основе чего формируется Лог по пользователю?

На основе логов по полям. Если логи по полю не записываются — то действия в этом поле не будут отражены в `логах по пользователю`.

#### <a name="logging-and-access-to-logs-q11"></a> Нагружают ли логи скорость записи в таблицу?

Да. Если у вас большая таблица в которую идет скоростная односторонняя запись — отключайте логи у полей в этой таблице.

#### <a name="logging-and-access-to-logs-q12"></a> Если name поля будет изменен, то что произойдет с логом?

Лог останется, но будет недоступен тк доступ к ним осуществляется по `name` поля.

#### <a name="logging-and-access-to-logs-q13"></a> Как ограничить доступ к логу только определенным ролям?

Укажите роли в [Лог доступен ролям][179].

## <a name="field-description-and-text-visibility-restriction"></a> Описание поля и ограничение видимости текста

### <a name="field-description-and-text-visibility-restriction-qa"></a> Вопросы и ответы

#### <a name="field-description-and-text-visibility-restriction-q1"></a> Как скрыть часть описания и показывать его только для админа?

Если в [описании][204] часть или весть текст заключить в тег `<admin>Скрытый текст</admin>` то он будет виден только ролям `Создатель`.

#### <a name="field-description-and-text-visibility-restriction-q2"></a> Можно ли использовать html для описаний?

В [описании][204] используется `html`.

#### <a name="field-description-and-text-visibility-restriction-q3"></a> Как расширить объем текста передаваемый в поле в web-интерфейсе и при печати?

Для оптимизации загрузки страницы в поля типа `текст` загружается только часть текста — какая именно определяет параметр [Ограничение видимости текста в web][147].

#### <a name="field-description-and-text-visibility-restriction-q4"></a> Можно ли скрыть часть описания таблицы?

Да, аналогично полю в [описании таблицы][117] можно использовать тег `<admin>Скрытый текст</admin>` текст заключенный в него будет виден только ролям `Создатель`.

#### <a name="field-description-and-text-visibility-restriction-q5"></a> Как по умолчанию открыть таблицу со свернутым описанием?

Для этого поставьте в начале текста тег `<hide>`.

#### <a name="field-description-and-text-visibility-restriction-q6"></a> Как запретить автоматическое разворачивание описаний полей в строке добавления?

Поставьте в начале описания тег `<hide>`.

## <a name="showing-the-field-value-as-a-url"></a> Показ значения поля как url

### <a name="showing-the-field-value-as-a-url-qa"></a> Вопросы и ответы

#### <a name="showing-the-field-value-as-a-url-q1"></a> Какой тип поля имеет параметр «показывать как url»?

[Строка][1].

В этом случае предполагается, что строка и является полным `url`, по которому будет осуществлен переход при клике.

#### <a name="showing-the-field-value-as-a-url-q2"></a> Пример: пример со связкой с кодом действия по триггеру он-дабл-клик

Но не только строка может быть оформлена как `url`. У кодов действий есть триггер [выполнять код действия при клике][509]. Он отрабатывает при двойном клике в поле если оно заблокировано.

У этого триггера есть расширение — [оформить клик как URL][510]. Если оно включено, то значение в поле будет оформлено в качестве `url` и действие будет выполнено при клике на него.

Например нам нужно открывать адреса на стороннем сайте в зависимости от номера удостоверения. Номера мы записваем в этом поле включили [выполнять код действия при клике][509] и [оформить клик как URL][510].

Код действия будет выглядеть приблизительно так:

```totum

= : linkToScript(uri: str`"https://example.org/document/" + $#nfv`; target: "blank")

````

## <a name="duplicate-lines"></a> Дублирование строк

### <a name="duplicate-lines-qa"></a> Вопросы и ответы

#### <a name="duplicate-lines-q1"></a> Что должно быть включено, что бы в таблице было доступно дублирование?

В параметрах таблицы — [Дублирование строк][110].

#### <a name="duplicate-lines-q2"></a> Как сохранить значение для полей вычисляемых кодом при дублировании строки?

Посмотрите [схему логики дублирования][493] в документации.

Если поле вычисляется кодом и у него отключен параметр [переносить значения при дублировании][153] то значение в новой строке будет рассчитано кодом, даже если в строке-источнике оно зафиксировано.

Если [переносить значения при дублировании][153] включен, то если в строке-источнике значение в поле зафиксировано оно будет перенесено в качестве закрепленного значения в новую строку.

#### <a name="duplicate-lines-q3"></a> Если нет кода, но установлено значение по умолчанию?

Если [переносить значения при дублировании][153] включено, то будет перенесено значение из строки-источника.

Если выключено, то устонавлено `значение по умолчанию`.

#### <a name="duplicate-lines-q4"></a> Дублирование строк с полем файл

Если [Дублировать файл при копировании][154] включено, то будет создана копия файла.

Если выключено, то поле будет ссылаться на оригинальный файл и кнопки управления в дублированной строке будут отключены.

#### <a name="duplicate-lines-q5"></a> Что произойдет при дублировании цикла?

Цикл дублируется целиком — поэтому коды действий при добавлении внутри таблиц не выполняются.

#### <a name="duplicate-lines-q6"></a> Как узнать id строки с которой было осуществлено дублирование?

При исполнении кода при добавлении в дублированной строке есть доступ к переменной `$#duplicatedId` которая содержит `id` строки с которой осуществлено дублирование.

Во всех остальных случаях она возвращает 0.

#### <a name="duplicate-lines-q7"></a> Как заменить стандартное дублирование?

Если в параметрах таблицу заполнить [код при дублировании из web-интерфейса][112], то он полностью заменит стандартный механизм дублирования.

#### <a name="duplicate-lines-q8"></a> Как обновить некоторые значения в дублированном цикле?

Цикл дублируется строкой в таблице циклов. Поэтому мы записываем кодом при добавлении `$#duplicatedId` и выполняем код действия при добавлении проверяя поле с `duplicatedId`.

Если `= 0` то ничего не делаем, если неравно, то выполняем внутрь цикла `set` или `recalculate`.

#### <a name="duplicate-lines-q9"></a> Если дублируется цикл с полем файл, то файлы будут сдублированы?

Аналогично дублированию поля файл в строчной части:

Если [Дублировать файл при копировании][154] включено, то будет создана копия файла.

Если выключено, то поле будет ссылаться на оригинальный файл и кнопки управления в дублированной строке будут отключены.

## <a name="panel-icons-recovery"></a> Панель, иконки, восстановление, наборы полей и дата актуальности

### <a name="panel-icons-recovery-qa"></a> Вопросы и ответы

#### <a name="panel-icons-recovery-q1"></a> Что такое панель и как ее активировать?

Это автоматическое представление строки в качестве двухколоночной [панели][105].

Если полей меньше 5 — то одноколоночной.

#### <a name="panel-icons-recovery-q2"></a> Как поля распределяются по колонкам в панели?

У полей по типам есть вес. Машина стремится распределить упорядоченные поля так, чтобы вес в правой и левой колонке был приблизительно одинаков.

#### <a name="panel-icons-recovery-q3"></a> При внесении изменений через панель в какой момент будут срабатывать триггеры на изменение?

В момент сохранения панели!

#### <a name="panel-icons-recovery-q4"></a> Как назначить таблице иконку?

За это отвечает параметр [Иконка][533].

#### <a name="panel-icons-recovery-q5"></a> Что такое режим Скрывать для удаления строк?

Удаление имеет два режима:

+ `удалять` — удаляется из баз без возможности восстановления.

+ `скрывать` - строка отмечается как скрытая и ее можно восстановить.

#### <a name="panel-icons-recovery-q6"></a> Как кодами получить доступ к скрытым строкам?

К скрытым строкам можно получить доступ только по `where: 'id' = ID_NUMBERS`.

#### <a name="panel-icons-recovery-q7"></a> При восстановлении срабатывает триггер на добавление?

Нет, восстановление не является добавлением.

#### <a name="panel-icons-recovery-q8"></a> Что такое наборы полей?

Создатель может преднастроить несколько наборов [видимости и размеров полей][552] и сохранить их для всех пользователей.

Хранятся они в настройке таблиц [наборы полей][123].

#### <a name="panel-icons-recovery-q9"></a> Зачем нужна дата актуальности?

Она нужна, чтобы сбросить у пользователей вид таблицы к текущим настройкам по-умолчанию, даже если у них включен свой специальнй вид.

Это нужно в тех случаях, когда добавляются поля или кардинально меняется верстка таблицы. В этом случае есть случаи, когда новые поля могут оказаться скрытыми для пользователя.

Чтобы пользователь гарантировано увидел таблицу так, как задумал разработчик — ставится [дата актуальности][122].

Если у пользователя активен вид, который он настроил раньше этой даты — таблица будет сброшена к виду по умолчанию.
