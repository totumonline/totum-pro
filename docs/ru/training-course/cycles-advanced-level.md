# Циклы продвинутый уровень

## <a name="table-versions-in-loops"></a> Версии таблиц в циклах

### <a name="table-versions-in-loops-qa"></a> Вопросы и ответы

#### <a name="table-versions-in-loops-q1"></a> Зачем нужны версии?

Например циклы используются для Заказов. Со временем вид и логика расчета заказа могут изменится.

Версии позволяют создать новую версию Заказа и назначать ее циклам с определенного момента.

Таким образом, при открытии старых заказов, они будут сохранять свою работоспособность.

#### <a name="table-versions-in-loops-q2"></a> Как создать новую версию таблицы в цикле?

Надо перейти в цикл и нажать `Создание версий тиблиц`.

Далее создание версии производится **дублированием!** с существующей версии.

Рекомендуется в названиях версии отражать ее статус — `текущая | разработка | устаревшая | итд.` тк название версии выводится непосредственно в цикле — это упрощает понимание того, в какую версию вы вносите изменения находясь непосредственно в цикле.

[Версии в циклах в документации —>][390]

#### <a name="table-versions-in-loops-q3"></a> Как выбрать версию таблицы для конкретного цикла?

За это отвечает `изменение версий таблиц цикла`.

Обновление версии таблицы происходит при первом ее открытии после изменения версии.

#### <a name="table-versions-in-loops-q4"></a> Как указать, какая версия таблицы должна назначаться при создании нового цикла?

Необходимо поставить галочку `по умолчанию` в [Версиях расчетных таблиц][357].

#### <a name="table-versions-in-loops-q5"></a> В какую версию вносятся изменения, когда мы меняем параметры поля?

В ту, которая в данный момент назначена таблице в цикле из которого вы редактируете поле.

## <a name="additional-version-parameters"></a> Дополнительные параметры версий

### <a name="additional-version-parameters-qa"></a> Вопросы и ответы

#### <a name="additional-version-parameters-q1"></a> Как поставить отображение таблиц в цикле в порядке, отличном от порядка их расчета?

За это отвечает поле `порядок` в [версия таблиц в циклах][358].

Оно берется при создании цикла из [версии расчетных таблиц][357].

#### <a name="additional-version-parameters-q2"></a> Как отключить автоматический пересчет таблицы в цикле?

За это отвечает поле `автоматический пересчет` в [версия таблиц в циклах][358].

Оно берется при создании цикла из [версии расчетных таблиц][357].

#### <a name="additional-version-parameters-q3"></a> Могут ли поля ярлыков обращаться в разные места в зависимости от версии?

Нет, не могут.

#### <a name="additional-version-parameters-q4"></a> Как получить версию таблицы кодом?

Взять кодом по `номеру цикла` и `name таблицы` из [версия таблиц в циклах][358].

#### <a name="additional-version-parameters-q5"></a> Где хранятся настройки отображений полей для таблиц внутри цикла?

В `fields_sets` в [версии расчетных таблиц][357].

## <a name="cycle-duplication"></a> Дублирование цикла

### <a name="cycle-duplication-qa"></a> Вопросы и ответы

#### <a name="cycle-duplication-q1"></a> Строку какой таблицы необходимо дублировать для дублирования цикла?

Строку в таблице циклов.

#### <a name="cycle-duplication-q2"></a> Выполняются ли коды при добавлении в хедерах и футерах таблиц внутри цикла при дублировании?

Нет, дублирование не является операцией добавления.

#### <a name="cycle-duplication-q3"></a> При дублировании цикла с какой версией создаются таблицы внутри цикла?

С той же, что и в цикле источнике.

#### <a name="cycle-duplication-q4"></a> Пример: пример переключения версии при дублировании

Логика такая:

1. Мы отслеживаем кодом при добавлении переменную `$#duplicatedId`

2. Кодом действя проверяем, и в случае если она `!= 0` выполняем set в [версия таблиц в циклах][358]:

```totum

=: set(table: 'calcstable_cycle_version'; field: 'version' = $version; where: 'cycles_table' = $#nti; where: 'table_name' = "table_name")

version: select(table: 'calcstable_versions'; field: 'version'; where: 'cycles_table' = $#nti; where: 'table_name' = "table_name"; where: 'is_default' = true)

```

## <a name="modification-of-the-open-button-to-guarantee-full-recalculation"></a> Пересчет цикла кодом и модификация кнопки открыть для гарантированного полного пересчета

### <a name="modification-of-the-open-button-to-guarantee-full-recalculation-qa"></a> Вопросы и ответы

#### <a name="modification-of-the-open-button-to-guarantee-full-recalculation-q1"></a> Как пересчитать цикл вручную?

Через выпадающее меню на `id` строки. это доступно только роли `Создатель`.

#### <a name="modification-of-the-open-button-to-guarantee-full-recalculation-q2"></a> Как пересчитать цикл кодом?

Это делает функция [recalculateCycle][304].

#### <a name="modification-of-the-open-button-to-guarantee-full-recalculation-q3"></a> Пример: пример модификация кнопки открыть для гарантированного полного пересчета

```totum

a1=: reCalculateCycle(table: $#ntn; cycle: #id)

a2= : linkToTable(table: $table; cycle: #id; target: 'self')
table: select(table: 'tables';  field: 'id' ; where: 'type'="calcs"; where: 'tree_node_id' = $nt; order: 'sort')
nt: nowTableId()

```

## <a name="synchronization-of-accesses-between-different-tables-of-cycles"></a> Синхронизация доступов между разными таблицами циклов

### <a name="synchronization-of-accesses-between-different-tables-of-cycles-qa"></a> Вопросы и ответы

#### <a name="synchronization-of-accesses-between-different-tables-of-cycles-q1"></a> Пример: Пример синхронизация доступов между разными таблицами циклов

Поле доступа `creator_id` может как обыкновенное поле изменяться кодом.

Поэтому, если вам надо синхронизировать доступ между несколькими таблицами циклов, то это делается через `set` по триггеру изменение:

```totum

=: set(table: 'cycle_2'; field: 'creator_id' = $#nfv; where: 'connector' = #id)

```

## <a name="tables-with-one-cycle"></a> Таблицы с одним циклом

### <a name="tables-with-one-cycle-qa"></a> Вопросы и ответы

#### <a name="tables-with-one-cycle-q1"></a> Пример: пример таблицы с одним циклом

Редко-используемый специальный режим работы, который позволяет пользователю создавать в таблице [циклов][89] только одну запись.

Если ее нет, то при первом открытии таблицы с одним циклом эта запись будет создана автоматически.

Доступа к циклам других пользователей нет и при открытии таблицы циклов происходит автоматический переход в цикл.
