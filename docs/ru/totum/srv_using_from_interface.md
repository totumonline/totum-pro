# SERVICES Выгрузка таблиц в xlsx, печать в pdf, превью docx/xlsx через конвертацию в pdf и загрузка xlsx

## <a name="srv-settings"></a> Включить доступные сервисы

В таблице `ttm__services` можно задать какие Сервисы будут активны для таблиц:

![srv](https://totum.totum.online/fls/365_709_file.png)

Вы можете выбрать для каких таблиц будет работать этот сервис. Можно указать конкретные таблицы или можно выбрать все и задать исключения.




## <a name="srv-xlsx"></a> (xlsx) Выгрузка таблиц в .xlsx

![xlsx](https://totum.totum.online/fls/365_710_file.png)

Когда для таблицы вабран XLSX — пользователи смогут скачать выведенную на страницу часть таблицы в `.xlsx`

- с заголовками полей

- без заголовков полей

Даты выгружаются в том виде, в котором они представлены визуально в полях таблицы.

Разделитель для десятичных можно задать в процессе экспорта.

Если выделить конкретные поля, то в выгрузку попадут только они.
