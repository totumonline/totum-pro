# Пользовательская документация

![](https://totum.totum.online/fls/365_600_file.jpg)

Настраивается в таблице `ttm__user_documentation`.

![](https://totum.totum.online/fls/365_598_file.png)

+ `name` — уникальный `name`.

+ `title` — заголовок, показываемый в выпадающем меню.

+ `link` — `url`, сылка на материалы. 

+ `for_roles` — список ролей, для которых будет показана кастомная ссылка.

+ `for_tables` — список таблиц, для которых будет действовать показ этой ссылки.
