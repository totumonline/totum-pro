# Настройка CSS

Если вы знаете CSS. Вы можете незначительно менять внешний вид схемы. Этот функционал предназначен для минимальных косметических изменений в системе и не годится для того, что бы сделать свой дизайн системы, так-как мы разрабатываем без учета обратной совместимости с кастомными дизайнами!

Добавьте значения `css` в поле `h_custom_css` таблицы `settings`.

Все, что находится в правиле для `body` будет применено к обеим темам. 

Все, что находится в правиле `body:not(.theme-dark)` будет применено только к светлой теме.

Все, что находится в правиле `body.theme-dark` будет применено к темной теме.

```css
body:not(.theme-dark){
	background-color: red
}
body.theme-dark{
	background-color: green
}
```

> Напоминаем, что правила CSS применяются последовательно.
