# Пользовательские цвета

**Только в PRO**

Пользовательские цвета — именованная палитра схемы в таблице `ttm__colors`. В кодах и настройках цвет из палитры записывается как `##name` (например, `##tomato`) вместо HEX или названия цвета HTML.

Для каждого цвета задается свое значение для светлой и для темной темы. Поэтому оформление предсказуемо выглядит в обеих темах, а поменять цвет во всей схеме можно правкой одной строки палитры.

## <a name="user-colors-table"></a>Таблица ttm__colors

Таблица `Пользовательские цвета` (`ttm__colors`) находится в ветке `PRO Пользовательские цвета`. Одна строка — один цвет:

| Поле | name | Что задает |
|---|---|---|
| Name цвета | `name` | Уникальное имя цвета, по нему цвет вызывается как `##name` |
| Светлый цвет | `light` | Цвет в светлой теме: HEX `#cf222e` или название цвета HTML |
| Темный цвет | `dark` | Цвет в темной теме. Если не заполнен — в темной теме берется светлый |

> Чтобы писать цвет в коде без кавычек, имя должно состоять только из латинских букв в нижнем регистре: `lightgray`, а не `light_gray` или `LightGray`. Подробнее — [Пользовательский цвет ##name][655].

Палитра передается в браузер при открытии страницы. После изменения цветов обновите страницу таблицы.

## <a name="user-colors-use"></a>Как записать цвет

+ В коде — `##name` без кавычек (см. [синтаксис][655]):

	```totum
	f1=: setFormat(condition: #quantity < 0; color: ##tomato)
	```

+ Разные цвета по условиям — несколько строк `f1=:`, `f2=:` с `condition` самого setFormat ([подробнее про форматирование][512]):

	```totum
	f1=: setFormat(condition: #final = true; color: ##green; bold: true)
	
	f2=: setFormat(condition: #final != true; color: ##gray)
	```

+ Значение `##name` — обычная строка `"##name"`, поэтому его можно записать и в кавычках или взять из поля. Например, цвет хранится в поле `color` строки (`##green`, `##tomato`, …):

	```totum
	f1=: setFormat(condition: #color != ""; background: #color)
	```

+ В настройках, которые задаются текстом, — просто `##name`: в [Цвет панели (panelColor)][176] — `##whitesmoke`, в [параметрах секций][455] — `plate: ##aliceblue`.

## <a name="user-colors-where"></a>Где работает

`##name` превращается в цвет палитры в браузере — в веб-интерфейсе таблиц, включая [анонимные таблицы][503]:

+ [setFormat][315] — `color`, `background`, `progresscolor`.

+ [setRowFormat][316] — `color`, `background`.

+ [setTableFormat][317] — `interlace`: `interlace: "##aliceblue/##whitesmoke"` (цвета нечетной и четной строк; в коде — в кавычках из-за `/`).

+ Настройка поля [Цвет панели (panelColor)][176] — заливка заголовка и тела поля.

+ [Параметры секций][455] — `plate` (цвет плашки) и `outline` (цвет обводки групп): `plate: ##aliceblue`, `outline: 1, 2 : ##gray`. В `border` цвет передается в CSS как есть — `##name` там не работает.

+ Кнопки [panelButtons][461] (контекстная панель поля) и окна [linkToButtons][446] — `color`, `background`.

+ Цвета канбан-колонок и форматирование карточек [вида панелями][487].

Не работает там, где цвет не проходит через веб-интерфейс: на сервере `##name` — просто строка. В печати, выгрузках xlsx и csv, в письмах и в html, которые формируются кодом (`linkToDataHtml`, `textByTemplate`, `emailSend`), она не заменяется на цвет — там используйте HEX. Не поддерживается также в цветах кнопок пользовательского меню.

## <a name="user-colors-dark"></a>Темная тема

+ `##name`, найденный в палитре, в светлой теме — `light`, в темной — `dark` (если `dark` пустой — `light`). Цвет берется как есть, без пересчета.

+ Обычные цвета (HEX и названия HTML) в темной теме Тотум затемняет автоматически — пересчитывает яркость и насыщенность, и результат не всегда удачный. Палитра позволяет задать темный вариант вручную.

+ `##name`, которого нет в палитре: Тотум отбрасывает `##` и использует `name` как название цвета HTML (с автоматическим затемнением в темной теме). Так `##tomato` работает и без строки в палитре, но выглядит как HTML-цвет `tomato`.

Общий CSS тем настраивается отдельно — [Настройка CSS][597].

## <a name="user-colors-agents"></a>Для агентов (MCP)

Визуальные форматы (цвета, жирность, заливка) в ответах MCP по умолчанию не выводятся. `read_table` и `get_row` с `styles: true` показывают их в синтаксисе setFormat — `-2 #style(color: ##tomato)` — и расшифровку цветов палитры в секции `## Styles`; `get_cell` показывает их всегда.
