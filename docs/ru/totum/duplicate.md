# Дублирование строк и циклов

## <a name="duplicate-rows"></a> Дублирование строк

![Алгоритм определения значения поля при дублировании](https://totum.totum.online/fls/365_329_file.png)

+ При активном [copyOnDuplicate][153] и отсутствии расчетного значения либо активном [codeOnlyInAdd][186] либо установленном ручном значении — значение из дублируемой строки. 

+ Если нет [default][141] либо [code][27] — значение из дублируемой строки.

+ Если тип поля [Уникальное][133] и было переопределено — пишется новое значение.

+ Во всех иных случаях значение расчитывается заново на основе данных новой строки.

## <a name="duplicate-cycles"></a> Дублирование циклов

При дублировании цикла значения в полях всех его таблиц дублируются полностью.

[Версии таблиц][390] в дублированной копии остаются такими же как и в дублируемом цикле.

> Коды действий на добавление не срабатывают.

## <a name="code-on-duplicate"></a> Код при дублировании

При наличии [кода при дублировании][112] он исполняется полностью вместо стандартного механизма дублирования.

При исполнении кода в нем будет доступна переменная `$#ids`, содержащая список `id` дублируемых строк (отмеченных галочкой).

## <a name="duplicate-var"></a> Быстрая переменная duplicatedId

> **Только для КОД** при добавлении дублированной строки!

```totum
ex: $#duplicatedId
```

Возвращает `id` строки, с которой было осуществлено дублирование.

Если добавление происходит не через дублирование, то возвращает `0`.
