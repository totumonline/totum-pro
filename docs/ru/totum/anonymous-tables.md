# Анонимные таблицы

Тотум позволяет открывать [временные таблицы][34] для внешнего доступа без авторизации в системе.

![Калькулятор времени](https://totum.totum.online/fls/365_368_file.png)

> При открытии анонимной таблицы используется пользователь `anonym`. Он должен быть включен и у него должен быть доступ на чтение или изменение к временной таблице к которой открывается внешний доступ.

Возможно использовать решение из нескольких таблиц вызываемых через [linkTodataTable][308]. Ко всем из них у `anonym` должен быть доступ.

![Unit-экономика](https://totum.totum.online/fls/365_369_file.png)

При помощи функции [linktoAnonymTable][443] можно зашифровать значения полей — эти значения будут подставлены при переходе по сгенерированной ссылке.

```totum
example: linkToAnonymTable(table: 'tmp_anonym_table'; params: $row)
row: rowCreate(field: "order_id" = 1111)

//Результат: htts://test.demo.totum.online/An/444?d=Y4EK1mpzeZtzxRcB58aMBQ06jVAtzVVU9A6bUo3oJbIP04JcHs7fdnD%2B9HCrh%2F4TUS9R0E4BLjfPXZ3slG%2FQgjJqGkheCb%2B8Hm53neuqHq2bbxdd5a2sjOIEBBvmnFES
```

Для шифрования передаваемых параметров предусмотрена настройка `соли`: `Системные таблицы` — `Основные` – `Настройки и крон` — `Настройки` — `Соль для анонимных таблиц`.

Также возможно передать `get/post/post-raw` параметры при открытии анонимной таблицы. При наличии в хедере таблицы полей `h_get`, `h_post` и `h_input` в них будут подставлены переданные данные.
