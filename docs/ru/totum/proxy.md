# Установка Totum PRO в сетях с промежуточным proxy

Если ваша конфигурация сети предполагает, что totum будет установлен на виртуальной машине не имеющей собственного внешнего ip-адреса, а маршрутизация запросов к системе будет осуществляться через proxy-сервер (например haproxy или любой другой), вам нужно учесть несколько моментов при установке.

1. Так как сертификат будет подключен к proxy-серверу, то установка totum должна осуществляться в режиме без сертификата. Для этого при выполнении скрипта установки необходимо оставить поде домена пустым, но на шаге подтверждения ip адреса надо указать домен, по которому будет осуществлятся доступ в браузере и на который будет отвечать proxy. Это важно для работы лицензии.

2. Proxy-сервер должен быть настроен таким образом, что бы на бекэнд пробрасывался host запроса — тот домен, которые пользователь вводит в браузере для доступа к системе. То есть домен на proxy, домен в Conf.php в корне установки totum и домен (хост) в лицензии должны совпадать.

3. Proxy-сервер должен быть настроен таким образом, что бы на бекэнд пробрасывались websocket запросы. Использование websocket можно увидет в конфигурационных файлах nginx [http](https://raw.githubusercontent.com/totumonline/totum-pro/master/totum/moduls/install/totum.online.conf.ip) или для [ssl](https://raw.githubusercontent.com/totumonline/totum-pro/pro/totum/moduls/install/totum.online.conf)

4. Хост (домен) по которому осуществляется доступ к системе должен быть доступен из консоли сервера на котором установлен totum. Проверить можно выполнив `curl -L YOUR_TOTUM_HOST`. Иногда сеть настроена таким образом, что запрос `local_totum_ip` -> `proxy_external_ip` -x `local_totum_ip` не выполняется. В этом случае необходимо указать в `/etc/hosts` внутренний ip proxy-сервера для домена системы, что бы запрос выполнялся по пути `local_totum_ip` -> `proxy_local_ip` -> `local_totum_ip`. Также на proxy могут возникать зацикливания `http` -> `https` редиректов. Если вы видите такую ситуация при выполнении `curl -IL YOUR_TOTUM_HOST` из консоли сервера totum, то поставьте в настройках proxy исключения для редиректа на запросы приходящие на внутренний ip proxy-сервера.

5. Proxy-сервер должен пропускать достаточный объем тела http-запроса. Например nginx по умолчанию имеет ограничение в 1мб. Если не перенастроить, то на практике это будет выглядеть как невозможность загрузить файл, объемом больше 1мб.
