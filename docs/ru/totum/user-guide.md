# Основы для пользователей

## <a name="scroll"></a> Горизонтальная прокрутка

Для того, чтобы быстро прокрутить таблицу вправо-влево используйте `CLICK+DRAG` или прокрутку на трекпаде или вашей `MAGIC MOUSE`.

![Прокрутка](https://totum.totum.online/fls/365_289_file.gif)

> В Windows горизонтальная прокрутка блока работает при `SHIFT` + `SCROLL WHEEL`

## <a name="vscroll"></a> Вертикальная прокрутка клавишами

`HOME` и `PAGE UP`, `PAGE DOWN` а также `UP`, `DOWN`.

## <a name="pointing"></a> Перемещение указателя

Если указатель установлен в одно поле, то стрелки на клавиатуре `UP`, `DOWN`, `LEFT`, `RIGHT` будут его перемещать указатель по ячейкам в пределах одного плейсмента.

Для Хедера и футера перемещение будет происходить по порядку полей.

`ESC` снимает пойнтинг полей.

Если указатель **не установлен** то `SHIFT+DOWN` или `SHIFT+RIGHT` установят в первое поле верхнего плейсмента, а `SHIFT+UP` или `SHIFT+LEFT` в последнее поле нижнего плейсмента.

Если указатель установлен, то аналогичные сочетания клавиш переведут указатель в следующий/предыдущий плейсмент.


## <a name="edit"></a> Редактирование поля

Поля на редактирование открываются двойным кликом левой кнопки мыши.

![Редактирование GIF](https://totum.totum.online/fls/365_288_file.gif)

Или при нажатии на `SPACE` (курсор в конце строки) или `SHIFT+ENTER` (с выделением содержимого).

> Если необходимо нажать на кнопку то `SPACE` в этом случае специально отключен, чтобы исключить случайное срабатывание — используйте `SHIFT+ENTER`.


**При открытом на редактирование поле:**

+ `ENTER`— сохраняет

+ `ESC` — отменяет

---

+ `SHIFT+ENTER` — сохраняет и переводит на ячейку вниз c выделением всего содержимого

+ `CTRL+ENTER` — сохраняет и переводит на ячейку вниз c установкой курсора в конец

+ `ALT+SHIFT+ENTER` — сохраняет и переводит на ячейку вправо c выделением всего содержимого

+ `ALT+ENTER` — сохраняет и переводит на ячейку вправо c установкой курсора в конец

> Для Хедера и Футера перевод будет осуществлен в следующее по порядку поле.

---

Можно редактировать несколько полей сразу, если такую возможность для колонки включил Создатель таблицы.

![Открыть поле на редактирование](https://totum.totum.online/fls/365_292_file.png)

Для числовых полей возможен ввод относительных значений. Для этого необходимо вместо текущего значения указать оператор и число.

+ `+10` — сложение, прибавит 10

+ `+-10` — вычитание, отнимет 10

+ `*10` — умножение, умножит на 10

+ `/10` — деление, разделит на 10

+ `%` — проценты:

	+ `+10%` — добавит 10%
	+ `+-10%` — вычтет 10%

## <a name="add-row"></a> Добавление строк

В зависимости от решения в таблице может быть разрешено добавление. Строки могут отображаться как сверху в порядке обратном добавлению, так и по месту сортировки. После перезагрузки страницы они всегда будут отображаться по месту сортировки.

![Строка добавления](https://totum.totum.online/fls/365_294_file.png)

Для строки добавления:

+  `ENTER` — сохраняет и переводит на ячейку вправо.

+  `ESC` — отменяет ввод.

+  `TAB` — сохраняет и переводит на ячейку вправо.

> Если вы только что сохранили строку, то нажатие `ENTER` откроет на добавление следующую.

## <a name="delete-row"></a> Удаление, дублирование и пересчет строк

+ **Удаление** — если разрешено, то удаляет строку.

+ **Дублировать** — если разрешено, дублирует строку/несколько строк. Новая строка/строки появляется под той, в которой вызвано меню дублирования и отмечается галочкой.

+ **Пересчитать** — обновить данные в расчетных полях.

![Дублирование](https://totum.totum.online/fls/365_296_file.png)

Если установлены галочки — то действие будет выполнено для всех выделенных строк и строки, из которой вызвано действие.

Если не установлены — то только для строки, из которой вызвано действие.

## <a name="multi-copy"></a> Выделение и копирование в буфер нескольких полей (вставка в Excel)

Вы можете выделять поля интервалами или произвольно:

+ `SHIFT+CLICK` — выделяет область.

+ `ALT+CLICK` — расширяет/уменьшает выделение на указанные поля.

![Выделение полей](https://totum.totum.online/fls/365_293_file.png)

При наличии выделенных полей — верхняя левая часть таблицы меняется на:

+ **Скопировать выделенные значения** в буфер обмена.

+ **Скопировать выделенные значения, заголовки и id строк** в буфер обмена.

Скопированные значения размечены для корректной вставки в таблицу Excel!

## <a name="filters"></a> Фильтры

### <a name="prefilters"></a> Фильтр таблицы (префильтр)

Префильтр (фильтр) — определяют какие строки будут переданы вам в браузер. Чем больше строк в таблице, тем дольше она будет загружаться.

![Префильтр](https://totum.totum.online/fls/365_301_file.png)

`Желтая заливка` — означает, что префильтр не применен и надо нажать `Go`!

### <a name="filter"></a> Фильтры колонок

**Действуют после Префильтра!**

В строчной части доступны быстрые фильтры по колонкам (должны быть включены Создателем таблицы).

Открыв фильтр, можно выбрать одно или несколько значений, по которым необходимо отфильтровать строки. Значения можно искать, задав его часть в поле поиска.

![Фильтры колонок](https://totum.totum.online/fls/365_298_file.png)

По умолчанию поиск в фильтрах осуществляется по пересечению совпадений частей введенных через пробел:

`Азот (20 счет)` найдется если ввести `Аз 20`.

#### <a name="filter-search-types"></a> Режимы поиска значений

По умолчанию поиск в фильтрах осуществляется по пересечению совпадений частей введенных через пробел:

+ `~~:` — так обозначен режим по умолчанию и эту комбинацию символов можно не вводить перед строкой поиска:

	`Азот (20 счет)` найдется если ввести `Аз 20`.

+ `!~~:` или `!:` —  режим по умолчанию с исключением:

	Если ввести `!: Аз 20` то покажет все, кроме `Азот (20 счет)` и аналогичных.

+ `~:` — пробел как символ:

	`Азот (20 счет)` найдется если ввести `~: от (20`.

+ `!~:` — исключить + пробел как символ.

+ `=:` полное соответсвие всего значения:

	`Азот (20 счет)` найдется если ввести `=: Азот (20 счет)`.

+ `!=:` — инвертированное полное соответствие.

+ `^:` — значение начинается с значения поиска:

	`Азот (20 счет)` найдется если ввести `^: Азот` или `^: Азот 20`.

+ `!^:` — инвертированное.

+ `^~:` — значение начинается + пробел как символ:

	`Азот (20 счет)` найдется если ввести `^: Азот (20`.

+ `!^~:` — инвертированное.

### <a name="value-filter"></a> Фильтр по значению в поле

Вы можете включить фильтр по значению поля нажав на поле правой кнопкой мыши и кликнуть на иконку фильтра.

![Фильтр по значению в поле](https://totum.totum.online/fls/365_299_file.png)

+ Если фильтр не был активирован до этого — он будет включен со значением поля, в котором вы кликнули.

+ Если фильтр был активен с несколькими значениями — то значение, на котором вы кликнули будет исключено из фильтра.

### <a name="multi-filters"></a> Несколько фильтров

Может быть назначено несколько фильтров — тогда будут показаны строки, подходящие под условия всех активных фильтров.

![Много фильтров](https://totum.totum.online/fls/365_300_file.png)

Активные фильтры выделены желтым. Помимо этого, кнопка Сброса тоже будет выделена желтым (моргает при обновлении страницы).

При клике на `Сброс` будут отменены все активные фильтры.

## <a name="view"></a> Настройки полей таблицы, наборы

Можно изменить размеры полей и их видимость, а также сохранить настройки и быстро между ними переключаться. Настройки сохраняются для связки пользователь-браузер.

![Глаз](https://totum.totum.online/fls/365_304_file.png)

+ `SHIFT+CLICK` — позволяет ставить/снимать диапазоны галочек.

+ Глаз **мигает желтым** если настройки видимости отличаются от стандартных. 

+ Клик **правой кнопкой** мыщи на *глазе* — загружает вид по умолчанию..
