# Реляционные взаимосвязи

## <a name="select"></a> Селект

Связь одной таблицы с другой, осуществляется через поле [Селект][36].

![Поле Селект](https://totum.totum.online/fls/365_343_file.png)

## <a name="value"></a> Значение — Отображение

Особенностью поля является то, что оно хранит строковое значение являющееся `id` строки в таблице источнике. В терминологии Тотум — `значение` или `основание`.

Пользователь же видит в поле не `значение`, а рассчитанное по формуле `отображение`.

![Значение - Отображение](https://totum.totum.online/fls/365_344_file.png)

## <a name="select-code"></a> Код Селекта

За расчет отображения отвечает параметр поля [код селекта][4]. Он выполняется перед отдачей данных в браузер пользователя.

```totum
= : selectRowListForSelect(table: 'products'; field: 'product'; order: 'product' asc;  preview: 'price'; preview: 'available')

```

Код селекта должен возвращать либо результат работы функций [selectRowListForSelect][227] и [selectRowListForTree][228], либо сформированный другими способами [список][14] [ассоциированных массивов][30].

Помимо `отображения` — функции селектов могут брать `preview` из таблицы источника для отображения в панели по правой кнопке мыши.

**Формат массива:**

	[
	{"value": 1, "title":"Alexey", "is_del": false},
	{"value": 3, "title":"Boris", "is_del": false,}
	{"value": 2, "title":"Pavel", "is_del": false,}
	]

+ **value** — `значение` поля.

+ **title** — `отображение` поля.

+ **is_del** — необязательный параметр, признак удаленности значения при активном параметре таблицы [скрывать при удалении][108].

Можно сформировать необходимый массив вручную функцией [rowListCreate][275].

## <a name="individual"></a> Индивидуальный расчет селекта

Селект может быть рассчитан единожды при загрузке таблицы, или пересчитываться заново для каждого поля при любом изменении в таблице.

Параметр поля [индивидуальный расчет селекта][194].

Используется если набор значений в селекте различается от строки к строке или зависит от других полей.

```totum
ex: selectRowListForSelect(table: 'products'; field: 'product'; where: 'price' > #min_price)

```

> Будьте внимательны — это сильно нагружает сервер и замедляет показ таблицы пользователю.

### <a name="select-nfv"></a> Гарантированный показ отображения выбранного значения

Часто бывает, что по условиям выборки необходимое `отображение` для выбранного в поле `значения` отсутствует. В этом случае оно будет показано в зачеркнутом виде.

![Нет отображения](https://totum.totum.online/fls/365_348_file.png)

Если вы хотите, чтобы выбранное значение по-прежнему имело отображение, выполните выборку через отдельный `select` и добавьте `текущее значение`:

```totum
//так будет зачеркнутое
ex_1: selectRowListForSelect(table: 'select_table'; field: 'select_field'; where: 'id' > 3)

//так будет дополнятся текущим
ex_2: selectRowListForSelect(table: 'select_table'; field: 'select_field'; where: 'id' = $id)
	id: listAdd(list: $listId; item: $#nfv)
		listId: selectList(table: 'select_table'; field: 'id'; where: 'id' > 3)
```


## <a name="select-value"></a> Берем значение через # или select

Когда мы берем значение [Селекта][36] через `#`, `@` или [select][225], то мы берем `значение`.

Если вам необходимо взять `отображение`, то используется `#s.select_field`, а для [select][225] параметр `sfield` вместо `field`. Если это [индивидуальный селект][194] то в параметры `tfield` необходимо указать поля от которых зависит расчет.

> Обращения через `#s.fieldname` и `sfield` сильно нагружают сервер, тк при каждом использовании рассчитывают отображения вызываемых селектов.


## <a name="multiply"></a> Множественные Селекты

Параметр поля [множественные значения][195]. При включенном параметре в поле будет храниться не одно значения, а [список][14].

![Множественные значения](https://totum.totum.online/fls/365_346_file.png)

Вы можете настроить отображение множественного селекта и показывать только количество значений — параметр поля [Отображение множественного селекта в ячейке][196].

> Обратите внимание: если вы создали одинарный селект, а потом перевели его в [множественный][195] вам необходимо пересчитать все строки таблицы.

> Аналогично для изменения [множественный][195] — одинарный. В этом случае при наличии выбранных в поле значениях часть из них будет утеряна.

## <a name="edit"></a>Редактирование источника из Селекта

Параметр поля [таблица селекта для изменения][201]. Если выбрана таблица, то если у пользователя есть возможность ее изменять — он будет видеть дополнительные клавиши управления.

![Таблица для изменения](https://totum.totum.online/fls/365_347_file.png)

## <a name="linkToPanel"></a> Обращения к источнику через linkToPanel

Можно обращаться к разным таблицам истоникам в зависимости от параметров в полях текущей или другой таблицы.

Параметр поля [панель селекта для изменения][202].

## <a name="basefield"></a> Другой basefield

По умолчания основанием (значением) является id в таблице источнике. Но вы можете указать другое строковое поле задав параметр `bfield`:

![base](https://totum.totum.online/fls/365_349_file.png)

```totum
ex_3: selectRowListForSelect(table: 'select_table'; field: 'select_field'; bfield: 'select_base')
```


## <a name="tree"></a> Селект-дерево

Тип поля [Селект-дерево][37] — позволяет оформить выбор значения в виде дерева.

![Дерево](https://totum.totum.online/fls/365_350_file.png)

Ожидает результат работы функции [selectRowListForTree][228].

Основным отличием функции является наличие параметра `parent` в таблице источнике, по которому определяется родительский элемент.


### <a name="self"></a> Варианты построения дерева

Тотум поддерживает два варианта дерева:

**Первый:** когда поле `parent` в таблице источнике берет значения из этой же таблицы (источника). В этом случае будет возможно разрешить выбирать папки [папки можно выбирать][199].

![По одной таблице](https://totum.totum.online/fls/365_352_file.png)

Код селекта поля Родительская категория:
```totum
=: selectRowListForTree(table: $#ntn; field: 'category'; parent: $#nf)
```

Таблица источник может быть [скрыта из дерева][121] для редактирующих ее ролей. Тогда изменение будет происходить через целевое поле.


**Второй:** когда поле `parent` является [селектом][36] из третей таблицы. В этом случае папки выбирать нельзя.

> В обоих случаях должен быть выбран соответствующий вариант в параметре поля [дерево строится по одной таблице][198].
