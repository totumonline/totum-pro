# Особенности кодов

## <a name="code"></a> Код

### <a name="calculation-sequence"></a> Последовательность расчета

Код — это формула, по которой вычисляется значение поля. При каждом расчете [единицы пересчета][494] он выполняется заново для каждого поля.

[Подробнее про Синтаксис ⟶][29]

Коды в таблице выполняются в [определенном порядке][494]:

![Код](https://totum.totum.online/fls/365_332_file.png)

> Если `Поле 2` обращается к `Полю 3` из кода через `#name_field_3`, то ответом будет [пустота][14], тк в указанном примере `Поле 3` рассчитывается после `Поля 2`.

Вы можете перенести отображение поля в [другой плейсмент][440] или [другой sort][442].

### <a name="recalculate-rows"></a> Пересчет строк

Для Рассчетных таблиц внутри цикла и Временных это неактуально так-как они рассчитываются всегда при открытии и при любом изменении.

Простые таблицы и таблицы Циклов в свою очередь имеют строчную единицу пересчета, те Коды в полях выполняются когда происходит изменение в одном из полей строки.

Чтобы пересчитать строки из интерфейса можно использовать Пересчитать:

![](https://totum.totum.online/fls/365_602_file.png)

Если у Кода включен дополнительный параметр [Выполнять только при добавлении][186], то простое Пересчитать не приведет к обновлению данных в этом поле. Это можно сделать написав код-действия с выполнением функции [recalculate][289] с указанными параметрами `field`.

Чтобы это упростить в **PRO** версии вы можете использовать `Пересчитать +`.

### <a name="executing-from-code"></a> Выполнение действия из Кода

Выполнение функций действий из кодов недоступно за исключением:

[reCalculate][289] — будьте внимательны, очень легко зациклить таблицу.

[Как чинить смертельный зацикл ⟶][480]

Применяется для того, чтобы обновить данные в таблице источнике и гарантировано брать свежие данные:

```totum
example1: while(preaction: $rec; action: $select)

rec: reCalculate(table: 'table_name')

select: select(table: 'table_name'; field: 'field_name'; where: 'id' = #item)

```

[getFromScript][312] — использовать с осторожностью. Если удаленный сервер не ответит, то вычисление свалится с ошибкой времени исполнения.

[linkToDataTable][308] — для расчета через скрытую [временную таблицу][34]. Смотрите следующий заголовок ...

### <a name="linktodatatable"></a> linkToDataTable в кодах

+ [linkToDataTable][308] — в кодах может быть использован вызов временной таблицы без ее показа пользователю.

Для этого при вызове должен быть передан параметр `hide: true`.

В этом случае будет возвращен хэш временной таблицы и из нее можно будет взять итоговые данные через `select`.

```totum
sel: selectRowList(table: 'tmp_table'; hash: $hash; field: 'data'; field: 'summ'; order: 'id' asc)
	~hash: linkToDataTable(table: 'tmp_table'; params: $row; hide: true)
		row: "здесь параметры передаваемые в tmp_table"
```

Такой способ генерирует нагрузку на базу данных, так как временные таблицы записываются и удаляются через час.

> Не рекомендуется использовать этот подход в строчных частях!


### <a name="old-in-code"></a> Использование old-значений

В кодах таже возможно использовать `old.` значения. Например:

```totum
example2: if(condition: #param = true; then: #old.number; else: #number)

// Пример кода для чекбокса, переключающий его в новое значение при каждом пересчете.

example3: if(condition: $#onfv = false; then: true; else: false)

```

## <a name="code-action"></a> Код действия

Коды действий выполняются после окончания расчета кодов.

### <a name="triggers"></a>Триггеры

Код действия поля запускается если срабатывает один из триггеров.

+ [CodeActionOnAdd][188] — запускать выполнение кода действия при добавлении строки/создании цикла.

+ [CodeActionOnChange][189] — запускать выполнение кода действия при изменении значения поля.

+ [CodeActionOnDelete][190] — запускать выполнение кода действия при удалении строки.

+ [CodeActionOnClick][509] — запускать выполнение кода при двойном клике на заблокированном поле.

### <a name="execution-sequence"></a> Последовательность исполнения

Порядок выполнения кодов-действий полей в таблице аналогичен [порядку][494] выполнения кодов.

![Код действия](https://totum.totum.online/fls/365_330_file.png)

### <a name="code-action-sintax"></a> Специальный синтаксис

Код действия может быть выполнен из секции `=:` — это простой вариант, если необходимо выполнить одно действие.

> Стартовая секция обязательно должна инициировать функцию действия! Это функции разделов [пересчет, вставка и изменение][338], [вызов окон и скриптов][339] или [логика][337]. 

```totum
=: reCalculate(table: 'table_name')
```

Может быть выполнено несколько последовательных действий:

```totum
a1=: set(table: 'table_name'; field: 'field_name' = #field)

a2=: reCalculate(table: 'table_name')
```

+ **a** — относится к любому триггеру.

+ **ch** — только изменение.

+ **ad** — только добавление.

+ **dl** — только при удалении.

+ **cl** — при двойном клике на заблокированное поле.

> Обязательно должен быть активен соответствующий триггер.

```totum
//выполнить при добавлении
ch1=: set(table: 'table_name'; field: 'field_name' = #field)

//первое действие при удалении
dl1=: reCalculate(table: 'table_name')

//второе действие при удалении
dl2=: reCalculateCycle(table: 'cycles_table'; cycle: #old.cycle)

```

Порядок исполнения по строчной сортировке цифры `12` `<` `2`.

`a` исполняются при любом триггере первыми.

#### <a name="code-action-while"></a> Несколько действий функцией while

Также несколько действий можно выполнить функцией [while][284]:

```totum

dl3=: while(action: $recalc; action: $cycle)

recalc: reCalculate(table: 'table_name')
cycle: reCalculateCycle(table: 'cycles_table'; cycle: #old.cycle)

```

#### <a name="code-action-listreplace"></a> Перебор списка функцией listReplace

[listReplace][486] позволяет последовательно выполнять действия перебирая список.

```totum
replace_act: listReplace(list: $list_date_act; action: $recalc_repl; value: "val_act")
	list_date_act: listCreate(item: "2020-09-10"; item: "2020-09-11"; item: "2020-09-12")
	recalc_repl: recalculate(table: $#ntn; where: 'date' = $#val_act)

// Выполняемый в коде действия последовательно пересчитает строки текущей таблицы в которой date равно датам из list_date_act.

```


### <a name="cod-act-features"></a> Особенности

+ При добавлении `old` значение равно [пустоте][5].

+ При удалении текущее значение равно [пустоте][5], если вам нужно удаляемое значение, то обратитесь к нему через `#old.fieldname`.

+ Сохранение данных в таблицу происходит по окончанию всех действий, поэтому функции [селект][225] из текущей строки могут брать устаревшие данные — используйте `#`.

+ Если в результате действия вы меняете значение, к которому обращается последующее действие, берите его через [селект][225]. Так как `#` берутся в момент выполнения **первого действия**.

+ [linkToDataTable][308] — вызов временной таблицы с передачей в нее параметров. Может использоваться для сложных модальных окон:

	![ДатаТабле](https://totum.totum.online/fls/365_339_file.png)

+ [linkToDataText][307] — открывает окно с простым текстом.

+ [linkToDataHtml][309] — открывает окно с html. Если вы хотите показать html-форму — используйте `linkToInput`.

+ [linkToPanel][310] — открывает строку таблицы как панель:

	![Панель](https://totum.totum.online/fls/365_340_file.png)

+ [linkToPrint][311] — вызывает окно печати:

	![Печать](https://totum.totum.online/fls/365_341_file.png)

+ [linkToInput][459] — вызывает окно ввода:

	![Ввод](https://totum.totum.online/fls/365_342_file.png)

+ [linkToAnonymTable][443] — специальная функция, шифрующая параметры для [анономных таблиц][503].

## <a name="format"></a> Форматирование

Секции кода условного форматирования:

[Поля][39] — наивысший приоритет. Ожидает возврат результата работы функции [setFormat][315].

[Строки][40] — средний приоритет. Ожидает возврат результата работы функции [setRowFormat][316].

[Таблицы][41] — низжий приоритет. Ожидает возврат результата работы функции [setTableFormat][317].

### <a name="format-sintaksis"></a>Специальный синтаксис

Возврат результата должен происходить из нумерованной секции `f1=:`, `f2=:`, ...

Порядок исполнения по строчной сортировке цифры `12` `<` `2`.

```totum
f1=: setFormat(condition: #type != 1; block: true; text: "—")
f2=: setFormat(condition: #type = 1; condition: $calc > $#nfv; background: "orange"; color: "white")

		calc: #price * 0.1 + #price

f3=: setFormat(condition: #type = 1; condition: #price > $#nfv; background: "tomato"; color: "white")

// При выполнении условий f3 перепишет f2
```

> Строка с большим приоритетом переписываеет указанные в ней параметры!

> Возврат к значению по умолчанию осуществляется указанием пустого значения —> `color: "";`.

Если вы хотите скомбинировать несколько действий, например вывести значение поля без пробелов и заглавными буквами, то:

```totum
f4=: setFormat(text: $upper)
	upper: strTransform(str: $repl; to: "upper")
		repl: strReplace(str: $#nfv; from: " "; to: "")
```

### <a name="panel-format"></a> Panel-функции

![Доппанель](https://totum.totum.online/fls/365_331_file.png)

Помимо `f` может быть использован префикс `p`, который будет выполнен в момент открытия панели по клику правой кнопки мыши на поле. Нумеруется аналогично `f`.

```totum
p0=: panelHtml(html: $strpanel)
	strpanel: strAdd(str: "Физически на Складе <b>"; str: $flat; str: "</b> из которых "; str: $block; str: " в резерве.")
		flat: select(table: 'goods'; field: 'count'; where: 'id' = #name)
		block: select(table: 'goods'; field: 'block'; where: 'id' = #name)

p1=: panelButtons(condition: $block != 0; button: $b1; refresh: true)
	b1: rowCreate(field: "text" = "ПОСМОТРЕТЬ РЕЗЕРВЫ"; field: "code" = "show_block")
	
p2=: panelButtons(button: $b2; refresh: true)
	b2: rowCreate(field: "text" = "ПОСМОТРЕТЬ ДВИЖЕНИЕ"; field: "code" = "show_move")

```

Обязательно должен возвращать результат работы функции с префиксом `panel...`:

+ [panelButtons][461] — размещает на панели дополнительные кнопки (одну или несколько).

+ [panelButton][565] — размещает на панели дополнительную кнопку (одну).

+ [panelImg][462] — размещает на панели изображение.

+ [panelHtml][463] — отображает на панели html.


> Panel-функции получают окружение той таблицы и строки, из которой были вызваны — `#id`, `$#nci`, `$#ntn`, `$#nti`. Дополнительные переменные можно передать через параметр `var:`.

> Panel-элементы будут доступны, даже если у [роли][366] доступ `только на чтение` — устанавливайте видимость через `condition` и [переменные][11] `$#nr` и `$#nu`.

### <a name="format-row"></a> Форматирование строк

### <a name="weak-block"></a> Слабая и сильная блокировка

> Любые блокировки `block`, `blockdelete`, `blockadd`, ... установленные в Форматировании являются слабыми, так как осуществляются на стороне браузера!

Сильными блокировками на стороне сервера являются:

+ [Префильтры][48]

+ [Тип доступа к циклам][116]

+ **Коды действий** в связке с функцией [errorExeption][287].

+ [Код действия таблицы][489] в связке с функцией [errorExeption][287]. Например:

```totum
ch5=: if(condition: #status != json`[1,2]`; then: $err)

err: errorExeption(text: "Нельзя изменить поле, если заказ в статусе Оплачен")

```
